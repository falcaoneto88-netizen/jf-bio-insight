# BioReport Studio

Crie a primeira versão de um aplicativo web chamado JF BioReport.

O objetivo é gerar relatórios clínicos premium a partir de exames de bioimpedância.

Nesta primeira versão, crie apenas:

1. Tela inicial premium

2. Upload de arquivo PDF, PNG ou JPG

3. Formulário clínico complementar

4. Tela de revisão dos dados do paciente

5. Botão “Gerar relatório”

Não implemente ainda a lógica completa de IA nem a geração real do PDF.

Design:

- médico

- premium

- minimalista

- branco, preto e dourado

- responsivo para celular e desktop

Fluxo:

Tela inicial → upload da bioimpedância → formulário clínico → revisão dos dados → gerar relatório.

Use componentes organizados em cards, botões elegantes, layout limpo e experiência profissional.
